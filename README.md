# 和弦助手 Chord Helper

一个可以装在安卓手机上的**吉他和弦查询**小工具（demo）。选主调、选级数、选和弦属性，立刻看到这个和弦在**整条指板上的全部按法**，按把位分组列出来，点任意一个指法就能在指板上高亮它，还能试听声音。

- 和弦、调音、鼓机、伴奏、作品、简谱/六线谱库**完全离线**；只有「即兴」里配置并使用大模型 API 时才联网。
- 不内置任何 API Key：厂商 / 模型 / Key 由用户自己填写，只保存在本机。
- APK 体积约 **223.3 KB**（界面是矢量 SVG 画的，没有图片素材）。
- 支持 Android 5.0（API 21）及以上。

## 一、它到底能做什么

| 能力 | 说明 |
| --- | --- |
| 主调（Key） | 12 个调，点一下切换；和弦名自动用惯用的升/降号拼写（如 F 调用 B♭，D 调用 F♯） |
| 音阶 / 级数 | 大调、自然小调、和声小调三种音阶；级数 1–7，可加 ♭/♮/♯ 变音 |
| 和弦属性 | 30 种：大三、小三、减三、增三、强力和弦、挂二/挂四/7sus4、大六、小六、6/9、add9、m(add9)、属七、大七、小七、小大七、半减七、减七、7♯5、9、maj9、m9、11、m11、13、m13、7♭9、7♯9、7♯11 |
| 调内和弦 | 当前调的自然三和弦 / 七和弦一览（I ii iii IV V vi vii°），点一下直接查 |
| 全把位指法 | 穷举 0–24 品里**所有**合法指法，按把位分组展示（默认 24 品，可改成 12/15/17/19/21/22） |
| 指板高亮 | 横放整条琴颈，显示品号、品记点、每个音的音名；当前指法用彩色圆点标出，空弦是绿圈、闷弦是 ×，横按画成一根横条 |
| 指法筛选 | 最大跨度（3/4/5 品）、最少发声弦数（3–6）、是否要求低音为根音、是否允许中间夹闷弦 |
| 试听 | 点 ♪ 用 WebAudio 实时合成拨弦音色扫一遍当前指法（不需要音频文件） |
| **调音** | 用麦克风收音，实时显示音名、频率、音分偏差（±50 音分指针）、最接近的琴弦，以及这个音在你所选调式里是第几级 |
| **调式音阶指板** | 主调 + 调式可任选，整条指板的每个音都标出**级数**和**按调式正确拼写的音名**（C 多利亚的 ♭7 写作 B♭ 而不是 A♯），主音用实心点，测到的音自动套高亮圈 |
| 教会调式 | 伊奥尼亚 / 多利亚 / 弗里几亚 / 利底亚 / 混合利底亚 / 爱奥利亚 / 洛克里亚，附起点、特征音、听感说明 |
| 基准音 | A4 可在 432 / 435 / 438 / 440 / 442 / 444 Hz 之间切换 |
| **伴奏（鼓机）** | 13 种常见节奏（摇滚 / 摇摆 / 放克 / 雷鬼 / 波萨诺瓦 / 圆舞曲 / 六八拍 …），BPM 40–240，可点速（TAP）、可调摇摆，节奏格子能自己改 |
| **伴奏（和弦）** | 按当前**调式**弹和弦走向：**63 条内置走向**（9 条经典 + 46 条歌曲/情绪 + 8 条扩展）+ 14 种节奏型（分解 / 扫弦），走向与节奏型都能自己新建编辑；分解型里第一个音是**根音**（C 和弦落 5 弦、G 和弦落 6 弦，自动跟着和弦走） |
| 一起播 | 鼓机、和弦伴奏各有独立开关，开几个就**一起响**且拍点自动对齐；**切到别的页签也继续响**，底部留迷你播放条 |
| **伴奏实例** | 把当前「鼓机（含格子改动）+ 和弦走向 + 节奏型 + 调式/速度」保存成一个实例，存在 SQLite；可保存多个、搜索、删除 |
| **即兴页（独立顶部页签）** | 选一个伴奏实例，或直接写一句**场景提示词**（例如“凄凉的秋天，一个老人扫落叶”）。主操作只有 **生成 / 保存** 两个按钮；生成后写 solo、出简谱并自动播放。任务队列一次跑一个，4 个 agent + 本地校验，SSE 流式显示思考过程。长度 1/2/3 loop（默认 1） |
| **提示词 → 推荐 agent** | 提示词不为空时，先由推荐 agent 从曲库里挑 **鼓机 / 节奏型 / 和弦走向**，给出 **1 个推荐速度**和 **Top 5 备选 BPM**。推荐面板里的三项配置可改；速度既可点 Top5，也可在数字框里输入 40–240。**点速度只记录选择，必须再点「用这些选择生成」才生成**。没有 API 时用本地情绪规则推荐，流程一样 |
| **作品（craft）** | 每次带提示词的创作会冻结成一条 craft：提示词 + 推荐结果 + 用户选择 + 伴奏实例 + 旋律 + 会话记录，全部写进 SQLite。详情页有**和弦图 + 节奏预览**、**双吉他指板**、三声部音量、**分页版本表格**；点开“我的作品”进入独立详情页，可以播放/停止、看简谱，并在会话框里继续让 AI 修改；对话里的每个版本都能点开预览，最终版本有明确标记 |
| **连音与八度** | 简谱数字**上方的点 = 高八度，下方的点 = 低八度**（每多一个点差一个八度）；`—` 是延音（连音）。生成后会主动增加跨拍延音，避免“每拍都换音”，长音可以连续占 2–3 格 |
| **设置与主题** | 右上角齿轮打开设置：厂商 / Base URL / 模型 / API Key、连接测试，以及 **跟随系统 / 浅色 / 深色** 主题；Key 只写本机，不内置、不打包 |
| **音乐风格 / 音色** | 风格 7 种：五声音阶、布鲁斯、蓝调、大调、自然小调、多利亚、混合利底亚；音色 6 种：民谣钢弦、古典尼龙、电吉他清音、电吉他过载、电吉他失真、爵士空心。每种音色有独立的泛音配比、衰减、琴体共振、拨片噪声和效果链，旁边有 **试听音色** 按钮 |
| **音域 / 离调 Bias** | **离调 Bias 0–100** 控制半音/离调音；**音域 Bias 0–1** 控制旋律离主音的音区跨度：0 约一个八度，1 约两个八度，并鼓励低/高八度呼应 |
| **三路音量** | 鼓 / 伴奏 / solo 各有音量滑杆；每路有独立的持续 gain 节点，**拖动时已经排期的音源也会立刻变**；有 solo 时伴奏自动让到 75% |
| **双吉他指板** | 左边旋律吉他：**整段固定一个主指型**，可选自动 / Mi / La / Si / Re / Sol（C 调示例：Mi 0–6、La 5–8、Si 7–10、Re 10–13、Sol 3–6 品）；个别音超范围会自动换把位并显示（虚线圈）；右边节奏吉他：当前和弦 + 低/中/高把位；两边圈内都显示**实际音名**（不是手指编号） |
| **逐音跟弹** | 简谱每格显示级数 + 音名；播放时当前格绿框、当前小节描边、顶部当前音读数、迷你条 `SOLO E4`，并自动横向跟随 |
| **四个 agent 之外** | 还有一个**确定性校验器**兜底：按 Bias 把越界音挪回允许音、清理孤儿延音、补空小节、检查格式；连续 3 个相同音会换掉；不盲信模型“说自己遵守了规则” |
| **简谱播放** | 旋律用上面 6 种音色播放；每种音色是独立的加法弦模型（泛音、衰减、琴体、拨片），不是只换波形；鼓机 + 伴奏 + solo 共用 Transport；乐器技巧会被真实合成出来 |
| **简谱 / 六线谱库** | 生成的谱可以存库，**简谱库里每条都有「播放」按钮**；库内直接标明来源和弦走向/实例。简谱可自动配和弦、生成六线谱；支持上传简谱图片（多模态模型）或文本导入；两个库都带搜索 + 分页 |
| 直达链接 | 支持 `#key=7&degree=5&q=maj9&maxFret=17` 这样的参数，可把你查到的和弦记成一条链接 |

指法卡片里的记谱和真实和弦谱一致：
`x` 表示闷弦，`0` 表示空弦，数字表示品位；圆点里的数字是建议指法（1=食指，2=中指，3=无名指，4=小指）。
卡片下方一行 `1 · 3 · 5` 是这根弦上各音在和弦里扮演的角色（根音/三音/五音…）。

## 二、怎么跑起来

### 方式 1：直接安装 APK（最快）

> 权限：`RECORD_AUDIO`（录音，只有点“开始收音”时才申请）+ `INTERNET`
> （只有「即兴」调用你自己配置的模型 API 时才用）。拒绝录音不影响其它功能；不配置 API 也能用本地规则生成 solo。

已经编译好的 APK 在：

```
dist/ChordHelper-1.3.0.apk
```

传进手机（微信/AI 助手/数据线/USB 都行），点击安装，允许「安装未知来源应用」即可。
安装包用的是 debug 签名，仅供自己试用；要上架应用商店请换成你自己的签名。

### 方式 2：用 Android Studio 打开（改代码用这个）

1. Android Studio 打开本目录（`File ▸ Open`，选到 `chord` 这一层，不是里面的 `app`）；
2. 等 Gradle Sync 完成（会自动下载 AGP 8.4.2 与 SDK 34）；
3. 点运行按钮装到手机/模拟器，或 `Build ▸ Build APK(s)`。

工程是标准 Gradle 结构，并自带 Gradle Wrapper，命令行也能直接编译：

```bash
./gradlew assembleDebug      # 产物 app/build/outputs/apk/debug/app-debug.apk
./gradlew assembleRelease    # 产物 app/build/outputs/apk/release/app-release.apk
```

`app/src/main/assets/www` 下就是全部界面代码。如果换电脑后 Sync 报 SDK 路径错，删掉 `local.properties` 让 Android Studio 重新生成即可。

### 方式 3：直接在浏览器里看（改界面用这个）

界面本身是纯静态网页，双击打开就能用，改 JS/CSS 刷新即可见效，不用编译：

```
app/src/main/assets/www/index.html
```

> 注意：`file://` 下 WebAudio 试听在部分浏览器会被拦截，用手机装 APK 后试听正常。
> 「即兴」的 AI 请求在 `file://` 桌面预览里也会被跨域拦截（原生 HTTP 桥只在 APK 里），
> 桌面上请点「生成」走本地 solo；真机 APK 里的 AI 生成、推荐 agent 与连接测试正常。

### 方式 4：不用 Android Studio 也能编译出 APK

本仓库自带一个只依赖 Android SDK（不需要 Gradle / AGP）的打包脚本，走的是 AGP 内部同样的流程
（`aapt2 compile/link → javac → d8 → zipalign → apksigner`）：

```bash
python tools/build_apk.py            # 产物在 dist/ChordHelper-1.3.0.apk
```

脚本会自动寻找 JDK 和 Android SDK（也可用环境变量 `JAVA_HOME` / `ANDROID_SDK` 指定）。
重新生成图标（纯 Python 画 PNG，不依赖 Pillow）：

```bash
python tools/make_icons.py
```

> 两条路径都能用，产出的 APK 内容一致（`dist/` 里这个包由 `tools/build_apk.py` 构建，
> 和 `./gradlew assembleRelease` 的产物逐字节同源，已交叉验证）。
> 装机时注意：Gradle 的 `assembleDebug` 产物包名是 `com.chord.helper.debug`，可以和 release 包共存。

顶部有四个页签：**和弦查询 / 伴奏 / 即兴 / 作品**。调音不占页签，点右上角、设置左边的调音按钮，会以 dialog 覆盖打开。

### 和弦查询

1. 点顶部 **⚙** 打开查询条件面板（底部抽屉）；
2. 依次选 **主调 → 级数（可加升降号）→ 和弦属性**；也可以在「调内和弦」那一排直接点某个级数一键选定；
3. 收起面板，下面就是**按把位分组**的全部指法；
4. 点任意一张指法卡片 → 上方指板立刻高亮该指法，指板会自动滚到对应把位；
5. **◀ / ▶** 在全部指法之间逐个切换，**♪** 试听当前指法。

几个好用的细节：

- 顶部 **♯/♭** 按钮可以手动切换和弦名的升降号写法（例如 G♭ ⇄ F♯）。
- 指板下方一行显示当前指法的**发声弦数、谱记法、以及每个音的级数**（`1`=根音、`3`=三音、`♭7`=小七…）。
- 高级设置里可以：改最大品、放宽/收紧跨度、要求 6 根弦全发声、关掉「低音必须是根音」来看**转位**指法、打开「指板上显示全部和弦音」看整条琴颈的和弦音分布、把指法卡片从「指法数字」切换成「音名」。
- 窄屏手机会自动压缩页头、收紧指板弦距，保证条件面板打开时指板依然完整可见；横屏/平板上面板会居中显示。
- 找不到指法时页面会给出可操作的建议（放宽跨度 / 允许转位 / 降低发声弦数），而不是空白。

## 四、调音 · 音阶（要麦克风）

点右上角、设置左边的 **调音按钮**，调音以 dialog 覆盖打开（不需要单独占一个页签）。进去后先选主调与调式，再对着琴收音；右上角「关闭」退出并释放麦克风。

**操作流程**

1. 点 **⚙** 选**主调**（C、E♭、F♯…）和**调式**（大调 / 自然小调 / 和声小调 / 七种教会调式）；
2. 点 **开始收音** → 系统弹一次麦克风授权（只申请这一次）；
3. 拨弦或哼一个音，界面会实时给出：

| 显示项 | 例子 | 说明 |
| --- | --- | --- |
| 音名（大字） | `B♭` | 按当前主调与调式拼写；准音时变绿，调外音用蓝色 |
| 频率 | `233.1 Hz · B♭3` | 实测基频与八度 |
| 级数 | `♭7 级` | 这个音在当前调式里是第几级；不属于调式会标「调外音」 |
| 琴弦 | `≈ 5 弦 A2` | 最接近的标准调弦空弦，方便判断在调哪根弦 |
| 音分 | `+31 音分 · 偏高` | 与十二平均律的偏差，±5 音分内判为「准」，指针会跟着摆 |

4. **音阶指板**（页签下方）：每个音位都标了 **级数 + 音名**，主音是实心橙点、其它级数是空心蓝圈，
   当前测到的音会套一个绿色高亮圈——既能看见调式的形状，也能立刻找到你刚弹的那个音在哪几根弦上。
   右上角按钮可以切换标注方式：`级数+音名` / `只级数` / `只音名`。
5. 最下面是**七种教会调式表**，点任意一行即可切换，比赛看谱还快。

**级数的口径**：级数按「与**同主音大调**相比改了哪些音」标注，和你给的那张表一致——
所以 C 多利亚的第 7 个音是 **B♭（♭7 级）**，C 大调的第 7 个音是 **B（7 级）**；
在降 E 多利亚里弹 B 自然音会显示 **♭6 级（调外音）**（那里的 6 级本来就是 C♭）。

**七种教会调式**（同一个调式换主调就是整体平移）：

| 调式 | 起点（相对大调） | 特征音 | 听感 / 典型风格 |
| --- | --- | --- | --- |
| 伊奥尼亚 Ionian | 大调 1 级起（= 自然大调） | 无 | 明亮、稳定 |
| 多利亚 Dorian | 大调 2 级起 | ♭3、♭7 | 小调但带亮色，爵士 / 放克 |
| 弗里几亚 Phrygian | 大调 3 级起 | ♭2、♭3、♭6、♭7 | 西班牙 / 弗拉门戈、阴暗 |
| 利底亚 Lydian | 大调 4 级起 | ♯4 | 梦幻、漂浮、电影感 |
| 混合利底亚 Mixolydian | 大调 5 级起 | ♭7 | 布鲁斯、摇滚、民谣 |
| 爱奥利亚 Aeolian | 大调 6 级起（= 自然小调） | ♭3、♭6、♭7 | 忧郁、小调 |
| 洛克里亚 Locrian | 大调 7 级起 | ♭2、♭3、♭5、♭6、♭7 | 极不协和，少用 |

（表里的「特征音」在应用里是根据调式音程**算出来**的，不是写死的：`Music.scaleCharacter()`。）

**调音是怎么算的**：`pitch.js` 用自相关（autocorrelation）+ 抛物线插值测基频，先把采样降到约 16kHz、
再用「第一个达到峰值 90% 的峰」判定周期，这样不会被琴弦的强泛音带跑调成低八度；
读数取最近 5 次的中位数，所以数字不会乱跳。实测单次检测约 1ms（台式机），手机上足够实时。
细节见 `process.md` 第 11 节。

**手机上没有麦克风/权限被拒**怎么办：页面会给出可读的提示（而不是白屏），和弦功能照常可用。

## 五、伴奏（鼓机 + 和弦伴奏 + 伴奏实例）

顶部 **伴奏** 页签。上面是总控（速度、谁参与、开始/停止），下面是两个子页签：
**鼓机** 和 **伴奏**。音色与和弦全部现场合成（不需要音频素材），
**切到「和弦查询」或「调音」页签也会继续响**，底部留一条迷你播放条随时能停。
两个子页签各有一个**启用**开关：都开就一起响，拍点自动对齐（共用一个时钟，不是各自计时后对齐）。

即兴已经搬到**独立的顶部页签「即兴」**，不再挤在伴奏页里。伴奏页多了一个「伴奏实例」面板：
把当前鼓机格子、和弦走向、节奏型、调式和速度保存成快照，之后在即兴页直接选它。

### 5.1 总控

- **速度**：拖动滑块、`-1 / +1`，或连点 **TAP 点速**（间隔超过 2.5 秒重新开始计算）；
- **谁参与播放**：`✓ 鼓机 已启用` / `✓ 伴奏 已启用` / `即兴 未启用`，点一下就能单独开关；
- **开始 / 停止**：所有已启用的引擎一起启停；状态行会写清楚当前在放什么。

### 5.2 鼓机（子页签一）

13 种常见节奏，点一下切换（切换时会带上该节奏的建议 BPM）：

| 节奏 | 拍号 | 建议 BPM | 说明 |
| --- | --- | --- | --- |
| 节拍器 | 4/4 | 90 | 只要一个干净的拍点，练音阶、对节拍 |
| 基础摇滚 | 4/4 | 100 | 底鼓 1、3 拍，军鼓 2、4 拍——最通用的四四拍 |
| 八分摇滚 | 4/4 | 120 | 连续八分闭镲、收尾开镲，扫弦练习的常用背景 |
| 流行 · 民谣 | 4/4 | 92 | 底鼓加在第三拍后半，弹唱伴奏最常见的律动 |
| 抒情慢歌 | 4/4 | 70 | 密度减半：底鼓在 1、军鼓在 3，适合慢歌分解 |
| 半拍摇滚 | 4/4 | 84 | 军鼓落在第 3 拍，听感比实际速度慢一半 |
| 蓝调摇摆 | 4/4 | 96 | 三连音摇摆（shuffle），十二小节布鲁斯标配 |
| 放克十六分 | 4/4 | 96 | 十六分闭镲 + 反拍军鼓（ghost note），练切分与闷音 |
| 雷鬼（One Drop） | 4/4 | 76 | 底鼓和军鼓同时落在第 3 拍，重音在反拍 |
| 波萨诺瓦 | 4/4 | 130 | 轻快拉丁律动，适合练右手分解 |
| 金属 · 双踩 | 4/4 | 140 | 八分连踩底鼓 + 每小节开头吊镲，练强力和弦 |
| 圆舞曲 3/4 | 3/4 | 120 | 「咚—恰恰」的三拍子 |
| 六八拍蓝调 | 6/8 | 100 | 六八拍摇摆（BPM 按八分算），慢速布鲁斯常用 |

点格子可以自己改：**点一下打点 → 再点一下加重音（琥珀色）→ 第三下取消**；
右上角 `↻` 恢复这个节奏的原样、`清空` 全部清掉。摇摆四档（直 / 轻摇 / 摇摆 / 重摇）只推反拍八分。

### 5.3 和弦伴奏（子页签二）

按当前**调式**把和弦走向弹出来——调式跟「和弦查询」页共用一个设置（点“改调式”会打开同一个面板）。
走向用**级数**表示，所以换调式时整条走向会跟着平移：同一个 `I–V–vi–IV` 在 C 大调是 `C G Am F`，
在 G 大调就是 `G D Em C`。

**9 条经典走向**（点一下切换）：

| 走向 | 说明 |
| --- | --- |
| 万能和弦 I–V–vi–IV | 华语流行最常用的一串，能套无数首歌 |
| 卡农 I–V–vi–iii–IV–I–IV–V | 帕赫贝尔卡农走向 |
| 五十年代 I–vi–IV–V | 老歌与民谣的经典四句 |
| 伤感流行 vi–IV–I–V | 从六级起，情绪偏抒情 |
| 民谣 I–IV–V | 三个和弦走天下 |
| 爵士 ii–V–I | 小七 → 属七 → 大七，最常见的爵士终止式 |
| 小调流行 i–♭VI–♭III–♭VII | 小调里最顺耳的一串（调式选自然小调） |
| 十二小节布鲁斯 | 蓝调/摇滚的根，配「蓝调摇摆」鼓机正好 |
| 老流行 I–vi–ii–V | 更“绕”的一条，适合副歌 |

**另外 54 条歌曲/情绪走向**：从常见华语流行走向整理而来，带 `歌曲` 标签，
包括「清新干净」（Am–F–C–G–Em）、「复古浪漫」、「追梦挣扎」、「老情歌」、
「海边微风」、「跨越山海」等 46 条，以及 `扩展` 标签的 8 条：
**4536251、日系 4536、流行八和弦 15634145、R&B 2516、爵士 4536251、
安达卢西亚终止、摇滚 I–♭VII–IV、小调史诗**。
每条的原调和弦写在说明里（如「原调 C：Am–F–C–G–Em」），实际播放仍按当前主调整体移调；
搜索框可以按情绪名、标签、当前调下的和弦名（如 `Am F C`）或 id 搜。

**列表很长时**：和弦走向、节奏型、鼓机节奏、调式表这四个列表都带**搜索框 + 分页**——
按名字、说明、拍号、分解/扫弦等关键字都能搜；每页固定条数，底部有「第 x / y 页 · 共 n 条」和翻页按钮。
保存新建的内容后会自动跳到它所在的那一页。

**新建和弦走向**：点右上角按钮进入编辑，每个和弦一行，可以选 **级数（1–7）→ 变音（♭/♮/♯）→ 和弦属性
（“自然”表示用该调式在这一级的本调和弦）→ 走几拍**，可以加/删和弦，保存后自动启用（列表里会标「自建」）。

**再改已经建好的走向**：每条走向（含自建的）行尾都有一个 **编辑** 按钮——
自建的直接原地修改（id 不变）；内置的会**复制一份**出来改，改完保存成新的自建走向，预设不会被污染。
自建的还多一个 **删除**。节奏型列表的操作完全一样。打开编辑器时页面会自动滚到编辑面板，不用自己往下找。

### 5.4 跟弹时看什么：顶上的大字就是当前和弦 + 走向预览

开始播放后，**页面最上方会用大字显示正在响的和弦**（大小和弦、七和弦都按实际写，如 `C`、`Am`、`G7`），
下面一行还标出它是走向里的第几个和弦、几级，以及这个和弦的组成音（`C(1) E(3) G(5)`）。
换和弦的时刻**和听到的完全同步**（跟着实际发声的事件走，不是按表推算）。

切到「和弦查询」或「调音」页签时，底部**迷你播放条上也有一份同样的和弦大字**——
这样你一边看指法/调式，一边也知道现在该按哪个和弦。

> 页头的大字只在「伴奏」页签显示；如果你切到别的页签又切回来，它会立刻恢复成当前和弦（不会空一屏）。

**走向预览就在它下面**（伴奏页总控区最上方，鼓机和伴奏两个子页签都能看到；
即兴是独立页，不显示这里的预览）：一串和弦块（`C 4拍 | G 4拍 | …`）+
节奏型的格子，播放时会跟着高亮当前和弦与当前格——比大字多告诉你"下一句是什么、这拍的节奏是什么"。

### 5.5 自建内容存在哪、下次打开还在吗

**在，关掉应用再打开也还在。** 存这些：

| 存什么 | 说明 |
| --- | --- |
| 自建和弦走向、自建节奏型 | 你新建/修改出来的内容 |
| 鼓机格子的改动 | 每个节奏上你自己点过的格子（内置预设不会被覆盖） |
| **伴奏实例** | 鼓机快照 + 走向 + 节奏型 + 调式/速度（`kind=instance`） |
| **简谱 / 六线谱** | 即兴生成、图片识别、文本导入后保存的谱（两个逻辑库） |
| **作品（craft）** | 提示词 + 推荐结果 + 用户选择 + 伴奏实例 + 旋律 + 会话记录（`kind=craft`） |
| 少量偏好 | 选中的走向/节奏型/鼓机节奏、BPM、启用开关；即兴的实例/风格/长度/音色/Bias/三路音量/上次的谱 |

手机上是 **本地 SQLite 数据库**（`chord.db`，用 Android 自带的 `SQLiteOpenHelper`，没有引入任何第三方库），
桌面浏览器里预览时自动改用 `localStorage`——所以两种情况都不用联网、也不用注册账号。

想确认到底存了没有，可以连上电脑看：

```bash
adb shell am start -n com.chord.helper/.MainActivity --es hash "tab=band&debug=1"
adb logcat -s ChordHelper/console:I      # 会打印：后端=sqlite chord.db{progression=1, rhythm=1} …
adb root && adb shell "sqlite3 /data/data/com.chord.helper/databases/chord.db 'select kind,id from items;'"
```

> 清空数据：手机「设置 → 应用 → 和弦助手 → 存储 → 清除数据」，自建内容会一起清掉（内置预设不受影响）。

**14 种内置节奏型**（分两页签展示，点一下切换）：

| 分解（指弹） | 说明 |
| --- | --- |
| 53231323 | 最经典的民谣分解，**第一个音弹根音**（C 和弦落在 5 弦、G 和弦落在 6 弦） |
| 四分分解 | 一拍一个音，慢歌与新手的起步节奏 |
| 根音交替 | 根音出现两次，弹出来更稳、更有低音支撑 |
| 三拍分解 | 3/4 拍（圆舞曲）的分解，配三拍子鼓机 |
| 六八拍分解 | 6/8 的摇摆分解（BPM 按八分算），慢速民谣常用 |
| 十六分分解 | 把 53231323 走成十六分，适合慢速下的铺底 |

| 扫弦 | 说明 |
| --- | --- |
| 民谣八分扫弦 | 「下 下上 空上 下上」——最常用的弹唱扫弦 |
| 四分扫弦 | 每拍一下，稳定好跟，适合练和弦转换 |
| 八分扫弦 | 一上一下均速循环，练右手稳定 |
| 十六分扫弦 | 十六分均速，快歌与情绪推进用 |
| 带切音扫弦 | X 是切音（闷住），流行与放克里常用 |
| 慢歌扫弦 | 留白多、起伏大，抒情歌的铺底 |
| 三拍扫弦 | 「强 弱 弱」的三拍子扫弦 |
| 反拍扫弦 | 只弹反拍，雷鬼与放克的味道 |

**新建节奏型**：先选 **几拍**（2/3/4/6）和 **每一拍几个格子**（1 = 四分，2 = 八分，4 = 十六分），
然后逐个格子点：
- **分解**：根音 → 1 弦 → 2 弦 → … → 6 弦 → 休止 循环；
- **扫弦**：下扫 → 上扫 → 切音 → 休止 循环。

这里的 **根音** 是关键的：走向里每个和弦的根音弦并不相同，所以节奏型里写“根音”而不是写死弦号，
引擎会按当前和弦的指法去找那根弦——这也是真实指弹的弹法。

想边看指法边跟节奏？直接切到「和弦查询」页签，伴奏不会停。

> 调音和伴奏会互相干扰：伴奏在响的时候麦克风会把声音一起收进去，应用里会给出提示
> （建议先停掉伴奏，或者戴耳机）。

### 5.6 即兴（独立顶部页签，AI 多 agent）

「即兴」是**第三个顶部页签**（右边是「作品」）。它根据一个**伴奏实例**写 solo：
实例 = 鼓机（含格子改动）+ 和弦走向 + 节奏型 + 调式/速度。
生成是把**实例走向 + 调式 + 风格 + Bias + 长度**交给四个手写 agent，
最后再经过一个**确定性校验器**，保证简谱格式正确、强拍落在和弦音上。
整条生成是**任务队列**里的任务：一次只跑一个，后面的排队；前端通过原生 SSE 流**边跑边显示思考过程**，
跑完才显示新简谱；播放时逐音高亮当前正在演奏的音。
没有用 LangGraph，也没有嵌入 Python——全部是页面里的 ES5 + 安卓壳的原生 HTTP 桥。

#### 一分钟上手

1. 在「伴奏」页配置好鼓机、和弦走向、节奏型（和速度），点 **保存当前为实例**，起个名字；也可以不选实例，直接写提示词让推荐 agent 建一个；
2. 点顶部 **即兴** 页签，在 **提示词（可选）** 里写场景/情绪，例如“帮我生成一段solo，生成一段凄凉的秋天有个老人扫落叶的场景”；
3. 点唯一的生成按钮 **生成**。提示词不为空时，先进入推荐流程：
   - 有 API：调用**推荐 agent**，从内置曲库里选鼓机、节奏型、和弦走向，并给出 **Top 5 BPM** 和推荐理由；
   - 没有 API：用本地情绪规则推荐（“凄凉 / 秋 / 落叶 / 老人”会落到抒情慢歌 + 慢歌扫弦 + 温柔忧伤），流程完全一样；
4. 推荐面板会列出推荐结果、三个可选下拉框、一个**可输入的速度数字框**、一个「推荐速度 66 BPM」快捷按钮和 Top5 快捷 chip。**点速度只会填入/高亮，不会立刻生成**；鼓机 / 节奏型 / 走向也能改成别的；改完点 **用这些选择生成**（或主按钮「生成」）才冻结伴奏实例并开始写 solo；
5. 生成过程在任务队列里跑，实时滚动 **思考过程（流式）** 和 5 个执行步骤；完成后才显示简谱并自动播放（鼓机 + 伴奏 + solo）；
6. 播放时每个格子标着级数 + 音名，当前音绿框高亮、当前小节有描边，顶部显示
   “正在演奏：第 N 小节 · 第 M 格 · 音名”，迷你条显示 `SOLO E4`；
7. 下面两块指板：左边旋律吉他（整段固定一个指型，可在下拉里选 自动/Mi/La/Si/Re/Sol，越界会提示换指型），
   右边节奏吉他（当前和弦 + 低/中/高把位）；
8. 带提示词生成的谱面会自动存成一条 **craft（作品）**，不需要再点保存；想更新当前作品时点 **保存**。

主操作区**只有「生成」和「保存」两个按钮**。播放/停止在作品详情页里；没有“本地 solo / 播放实例 + solo / 停止”这一排按钮了。
提示词为空时，仍然按当前选中的伴奏实例生成，不进入推荐流程。

#### 推荐 agent 与 Top 5 速度

推荐 agent 不是让模型自由发挥，而是把**可用的鼓机 / 节奏型 / 走向 id 列表**放进提示词，要求它只输出：

```json
{"title":"作品名","drumId":"ballad","rhythmId":"strum_ballad",
 "progressionId":"song_tender","bpmTop5":[58,62,66,70,74],
 "reason":"提示词偏凄凉/秋日，推荐慢速抒情鼓、扫弦垫底和温柔走向。"}
```

- 返回的 id 会再经过本地白名单校验；模型编了一个不存在的 id 就回退到本地推荐；
- `bpmTop5` 会被去重、按升序排列、补足 5 个，并限制在 40–240 BPM；
- LLM 请求失败时不会卡住流程，自动降级成本地推荐，并在页面上说明原因；
- 推荐结果、用户选中的 BPM、以及每个选择对应的名称都会一起写进 craft，之后再打开还能看到“推荐了什么、用户选了什么”；
- 推荐面板里的三项配置来自内置曲库（也会带上你自建的走向/节奏型），点速度不会触发生成，避免用户还没改完就花掉一次模型调用。

#### 作品（craft）与详情页

带提示词生成后会自动写一条 craft（SQLite `kind=craft`），内容包括：

- 提示词、推荐结果、用户选择（BPM / 鼓 / 节奏型 / 走向）；
- 完整的伴奏实例快照（鼓机格子、走向、节奏型、调式、速度）；
- 生成的简谱、音色、风格；
- 后续会话记录（`user` / `assistant` 每条消息和时间）。

打开顶部 **作品** 页签（在「即兴」右边），默认停在「作品库」。每行显示标题、提示词摘要、BPM、走向/鼓/节奏型，点 **打开** 会进入**独立详情页**：

- 最上方是固定（sticky）的 **← 返回作品库** 按钮，滚到哪都能回去；
- 顶部是标题、提示词、播放作品 / 停止，以及鼓 / 伴奏 / solo 三声部音量；
- 接着是 **伴奏预览**：走向里的每个和弦都有一张真实和弦图（音名标注）+ 拍数，下面是和伴奏页一样的节奏格子；播放时会同步高亮；
- **双吉他指板**：和即兴页一样左右两块指板，左边显示旋律指型（自动推荐的 Mi/La/… 和品格窗口，可手动换指型），右边显示当前节奏和弦及低/中/高把位（可切换）；
- 「推荐与选择」卡片列出推荐鼓机、节奏型、走向、单个推荐速度、Top5 和你的实际选择；
- **版本记录表格**：列出版本、速度、鼓机、节奏型、和弦走向、修改提示词、时间和操作；每页 5 条，底部可以翻页。初版是 v1，最终版本有绿色「最终」标记；每一版都能点 **预览**，简谱区会写清“正在预览 v1（最终 v2）”，并可以 **回到最终版本**；
- 最下面 **继续修改** 会话框：输入“第二小节太密了，帮我留一点呼吸”这类要求，AI 会返回新的合法谱面；
  助手回复里直接带 **预览 vN** 按钮和「最终版本」标记，对话、版本和改后的谱面都会立刻写回同一条 craft；
- 详情页是独立一屏，会隐藏底部页签、页脚说明和全局迷你播放器，避免挡住谱面和输入框；左上角 **返回即兴**。

没有 API 时仍可打开作品、播放、查看会话；发送修改会明确提示“还没有配置 API”，并把这条失败的助手回复也记录在会话里，不丢上下文。

#### 保存后的简谱怎么播放

作品库每条 craft 点开后直接播放。若要听老的单条简谱，切到顶部 **作品 → 简谱库**，每条行尾仍有 **播放 / 载入 / 删除**：

- **播放**：先把这条谱载入，再按它保存时关联的伴奏实例播放（鼓机 + 伴奏 + solo）；
- 如果关联的实例已经被删，或者这条谱是文本/图片导入、没有实例，播放按钮会**只播旋律**，
  不会拿当前页面上另一条实例的伴奏硬配；
- 行内会写清 **「走向：… · 实例：…」**，谱面上方的信息行和生成任务标题也会显示来源走向；
- **载入**只把谱面放到编辑区，不自动发声。

**来源标注**：生成的简谱保存时会把 `progressionName / instanceName` 一起写进 SQLite；
旧版本保存的谱没有这两个字段时，会从谱面里的走向快照 `.zh` 补出来。
谱库搜索也支持按走向名、实例名和来源走向搜。

没有 API 时点 **生成** 会走本地规则作曲：用同一套乐理规则在本地写一段，用来听效果或给 AI 生成做兜底。
顶部会有一行很显眼的 **模式条**：绿色是 `LLM solo · 模型名`，橙色是 `本地 solo`。
谱面信息里也会标 `LLM solo / 本地 solo / 图片识别 / 文本导入`。

#### 设置与主题

右上角齿轮（不是和弦查询里的条件齿轮）打开 **设置**：

- 厂商 / Base URL / 模型 / API Key；可以点 **测试连接** 验证，再 **保存并关闭**；
- **外观主题**：跟随系统 / 浅色 / 深色。选择会立刻生效并记住；老 WebView 不支持 `prefers-color-scheme` 时也能靠显式 `data-theme` 覆盖；
- Key 只写本机 SQLite / localStorage，不内置、不打进 APK、不写进仓库；换设备或清除数据需要重新填写。

#### 伴奏实例与长度

- **保存**：在「伴奏」页点「保存当前为实例」，或在「即兴」页点「用当前伴奏新建」；
  两种都会弹出名称 dialog，把当时的鼓机格子、走向、节奏型、调式、速度冻结成快照写入 SQLite（`kind=instance`）。
- **选择**：即兴页的实例区域有**搜索框**，按实例名、和弦走向、调式、节奏或 BPM 过滤；
  下拉框只列匹配项，选中的实例才生效。切换实例会清掉当前未保存的谱面，避免拿旧 solo 配新伴奏。
- **长度**：`1 / 2 / 3 个 loop`，默认 1。实例本身是 4 小节（十二小节布鲁斯就是 12 小节）一个 loop，
  选 2 就是 8 / 24 小节，和弦网格自动循环。
- **删除**：即兴页或伴奏页的实例行都有删除按钮。

#### 双吉他指板（整段一个指型，可选择）

- **左边旋律吉他**：默认「自动」会给整段 solo 选**一个**覆盖最多的指型，不会每 2 小节换把，
  所以不会出现“弹到 1 级突然跳到 6 品、只用 1–3 弦”的跳把。
- 指型下拉可以手动指定 **Mi / La / Si / Re / Sol**，选项里直接写出当前调式的品格范围。
  以 C 调为例：Mi 0–6、La 5–8、Si 7–10、Re 10–13、Sol 3–6 品。
- 切换指型后整段指板和当前音都会按同一个主窗口重排；选择会记住。
- 如果有个别音落在主窗口外，**自动换把位把它显示出来**（窗口中会扩展到该品，虚线/琥珀色圈表示换把音），
  不会像上一版那样直接不画；同时提示“这几个音超出 La 指型，已换把显示；也可换 Mi/Sol 型”。
  主指型仍覆盖大部分音，不会每 2 小节整体换把。
- 指板上用淡点画出该指型的音阶位置，用空心圈标出这段旋律用到的音，当前正在弹的音用实心点 + 音名高亮；
  圈内显示实际音名（C/E/G…），下方列出整段 solo 用到的音（如 `C D E G A`）。
- **右边节奏吉他**：显示当前小节的和弦，按 **低 / 中 / 高把位** 选择指法；播放时跟随和弦切换。
  这个把位也真的会作用到伴奏引擎（分解/扫弦用同一个指法）。

#### 任务队列与流式思考

- **FIFO 队列**：生成按钮每点一次创建一个任务；正在跑时再点会**排队**，不会并发打 API；
  任务行显示 `排队 / 运行中 / 完成 / 失败 / 已取消`，可以取消排队、重试失败、载入已完成的结果。
- **流式**：安卓壳 `HttpBridge.streamPost()` 逐行读取 SSE 并回调 `window.__httpChunk`；
  `LLM.streamChat()` 把 `reasoning_content` / `content` 片段交给页面。桌面浏览器用 `fetch + ReadableStream`，
  不支持时自动回退整段返回。
- **思考过程**：模型输出里的 `thinking / structure / motif / density / contour / review / reason / idea`
  会被抽成可读段落（不是把整段 JSON 硬塞给用户），并保留每个 agent 的标题与耗时。
- **结果时机**：任务运行期间简谱区显示“任务运行中，完成后会显示新的简谱”，**完成后才渲染谱面**；
  完成后自动播放。
- **逐音显示与高亮**：每个音符格显示“级数 + 音名”（如 `5 / G4`）；播放时当前格绿框、当前小节描边、
  顶部当前音读数、迷你条 `SOLO` 和左指板同步，超出屏幕会自动横向滚到当前小节。

#### 四个 agent 到底在干什么

| 步骤 | 角色 | 输入 | 输出 |
| --- | --- | --- | --- |
| 1 | **主控 Agent** | 调式、走向、风格、Bias、小节数 | 结构规划：2 小节动机、call/response、音区走向、每小节的落点 |
| 2 | **填音 Agent** | 上一步的规划 + 每小节和弦音 | 每小节 8 个八分格的简谱：`0` 休止、`-` 延音、`[b/#]1–7` 音符；要求动机重复/变化、留出呼吸 |
| 3 | **衔接 Agent** | 已写好的谱面 | 小节交界/小节内相邻音的吉他技巧：`slide` 滑音、`bend` 推弦、`hammer` 击弦、`pull` 勾弦、`vib` 揉弦；前一个位置必须是实际音符，否则校验器会拒绝滑/推/击/勾 |
| 4 | **润色 Agent** | 初稿 + 和弦网格 + 风格 | 按“动机是否发展、是否留白、句尾是否落和弦音、有没有连续重复/无意义跑句”评审并重写一版 |
| 5 | **本地校验器**（不是模型） | 谱面 + 和弦网格 | 按 Bias 修掉越界音、清理孤儿延音、补空小节、检查格式 |

降级策略：主控失败会继续填音；衔接失败会自动用本地启发式补技巧；润色失败保留初稿；填音失败才整条失败。
每次模型请求都有超时（125 秒），解析失败会自动重试一次。

#### 风格与 Bias

| 风格 | 可用音（相对主音） | 味道 |
| --- | --- | --- |
| 五声音阶 | 1 ♭3 4 5 ♭7 | 摇滚/流行 solo 最稳，不容易错 |
| 布鲁斯 | 五声音阶 + ♭5 | 蓝调音、推弦与滑音 |
| 蓝调 | 布鲁斯 + 2 3 6 9 | 大小三度混用，更爵士、更“花” |
| 大调 | 1 2 3 4 5 6 7 | 直接、明亮，流行 / 民谣 |
| 自然小调 | 1 2 ♭3 4 5 ♭6 ♭7 | 忧郁、深沉 |
| 多利亚 | 1 2 ♭3 4 5 6 ♭7 | 小调带亮色，爵士 / 放克 |
| 混合利底亚 | 1 2 3 4 5 6 ♭7 | 大调带 ♭7，布鲁斯 / 南方摇滚 |

音色下拉有 6 种：民谣钢弦、古典尼龙、电吉他清音、**电吉他过载**、电吉他失真、爵士空心。
过载/失真是真的经过 `WaveShaper` 软削波，不是把音量调大；1.2.4 起用带偏置的**非对称削波**
（产生偶次谐波）+ 2.3/2.8kHz presence + 箱体低通，避免失真发闷成“哑 du”。
每种音色的泛音配比、尾音长短、琴体共振和拨片噪声都不同，所以钢弦、尼龙和电吉他听起来
不是同一个“du”；旁边点 **试听音色** 会立即用当前音色弹一小段。
钢弦额外加了 3.4kHz 的亮度与更强的拨片；电清音用 700Hz 中频凹陷 + 2.5kHz 拾音器式存在感，
延音更长，尽量接近钢弦/单线圈清音。

**Bias**（0–100）控制离调程度：

- **0–20**：只用当前和弦的和弦音；
- **21–65**：强拍仍要求和弦音，弱拍可以加风格音阶；
- **65 以上**：弱拍放开半音，允许经过音/蓝调音。

校验器会真的把不合规的音移到最近的允许音（日志里能看到“修正了几处”），不是只在提示词里“建议”。

**音域 Bias（0–1）** 是另一个参数，和上面的离调 Bias 不冲突：

- `0`：旋律主要在一个八度内；
- `0.5`（默认）：约 1.5–1.7 个八度；
- `1`：约两个八度，鼓励低八度/高八度的呼应。

本地作曲会把前两小节放在中低音区、后两小节抬到中高音区；AI 的 planner/filler/polish 提示词
都会带上目标 MIDI 音域。音域是作为提示词交给模型的，程序**不会事后移八度改写 AI 写的旋律**；
如果模型写得仍然太窄，可以提高音域 Bias 后重新生成。本地作曲则直接用这个范围生成高低呼应。

**旋律指板上的音**：左边旋律吉他的空心圈内显示音名（如 C/E/G），右边节奏和弦的圈内也显示
实际音名，而不再显示 1–4 的手指编号；当前正在弹的音仍用实心点 + 音名（如 `F4`）高亮。

**八度点**：数字**上方**的圆点表示高八度，**下方**的圆点表示低八度；两个点就是差两个八度。
每个音下面还有音名和八度（如 `A3`），可以互相核对。`—` 是延音（连音）。

**连音/延音**：生成后会做一轮连音润色，把一部分相邻音合并成延音，并把句尾空拍延长；
本地旋律平均每小节至少有 1 个延音，AI 提示词也要求每小节至少 2 个 `-`，长音可以跨过拍点持续 2–3 格。
这样比“每拍一个音”更连贯；`0` 仍然是真正留白。

#### 简谱长什么样

**拍子分组**：简谱每两格是一拍，四拍用浅/深交替的背景块隔开；不再是一整排格子，能一眼看出音落在第几拍。

- 每小节固定 **8 个八分音符格**（4/4 拍，每格半拍）；
- `0` = 休止，`-` = 延音（延长前一个音），`3` = 级数 3；
- `b3` / `#4` 是变音；数字后加 `'` 是高八度，加 `,` 是低八度；
- 技巧标在“目标音”上，谱面上会显示「滑/推/击/勾/揉」小标签；
- 播放时延音不会重复拨弦，会按实际时值合成一个长音。

#### 播放与音色

- **旋律音色**：默认 **电吉他清音**，下拉里还有民谣钢弦 / 古典尼龙 / 电吉他过载 / 失真 / 爵士空心；
  旁边 **试听音色** 会立刻弹 C–E–G–C，方便对比；
- **合成方式**：每个音由 6–8 个泛音组成，高次泛音衰减更快；每种音色另有自己的琴体共振峰、
  拨片/琴体瞬态和低通曲线，电吉他还有轻微失谐；过载/失真走真 `WaveShaper` + 箱体低通。
  末端有软限幅，多个音同时响不会爆音；
- **solo 混音**：solo 走一条单独的总线（中高频 +4.5dB、轻微压缩、1.5 倍），伴奏在有 solo 时自动让到 75%，
  单音旋律不会被整串扫弦盖住；
- **三路音量**：鼓 / 伴奏 / solo 各有滑杆（默认 80% / 100% / 120%），都保存在本机；
  每路有一条持续 gain 总线，拖动滑杆会立即改变已经排期的音源，不需要等下一轮；
- **伴奏调度**：实时伴奏**一次只排 1 拍**（不是整个和弦/整条走向），每次最多创建几十个振荡器；
  伴奏声部用 5 个泛音并关闭 chorus，避免手机音频线程被成百上千个节点压到丢音；
- **密度与连奏**：默认每小节 5–6 个音；AI 提示词要求至少 2 个延音 `-`，本地旋律至少 1 个（有空间时 2 个），长音跨拍；
  小节内相邻音会按音程补击弦/勾弦/滑音，小节交界也会补衔接；`0` 仍然是休止；
- **当前音**：播放时迷你条会显示 `SOLO E4`，简谱格子和左边的旋律指板同步高亮；
- **人性化**：布鲁斯/蓝调会把反拍往后推一点，音符有 ±6ms 的微抖动和强弱拍重音，不再是节拍器式的机械音；
- **旋律 + 伴奏**：和鼓机、和弦伴奏共用同一个 `Transport`，启动时对齐到同一时刻，拍点不会漂；
- **技巧**：滑音/推弦会从低 2 个半音滑上来，击弦/勾弦有装饰音，揉弦是延迟起的 LFO；
  只有前一个位置是**实际拨响的音符**时才允许滑/推/击/勾（小节内相邻音也算），
  上一小节以延音或休止结尾时会跳过；
- **停止**：沿用 12.9 的“掐音源”机制——停止会真的把已排期的音源全部杀掉，不是只停定时器。

#### 工具

| 工具 | 说明 |
| --- | --- |
| **上传简谱图片识别** | 选图 → 多模态模型识别成结构化简谱 → **自动写入简谱库 + 六线谱库**。DeepSeek 聊天模型**不支持图片**，请选 OpenAI（如 `gpt-4o-mini`）或自定义多模态模型 |
| **文本导入简谱** | 没有多模态模型时用。格式见下面 |
| **根据简谱配和弦** | 按强拍/首尾音权重、和弦音重合度、上一小节延续与下行五度打分，逐小节给出 C / F / G / C 这样的建议；一键设为当前走向 |
| **生成六线谱** | 把旋律按“最近把位”分配到 6 根弦与品位，生成文本六线谱并写入六线谱库 |

文本导入格式（每行一小节，左边可选的弦名/和弦名）：

```
title=我的谱
key=C
mode=major
bpm=100
C | 1 3 5 1
G | 5 7 2 5
```

`C | 1 3 5 1` 里的 4 个音会展开成 8 个八分格 `1 - 3 - 5 - 1 -`；
也可以直接写 8 个格子。`0` 休止、`-` 延音、`b3` 变音、`1'` 高八度、`1,` 低八度。

#### 存在哪

手机上是同一个 `chord.db`，用 `items(kind,id,json,updated_at)` 的 `kind` 分逻辑库：

- `instance`：伴奏实例（鼓机快照、走向、节奏型、调式、速度、把位）；
- `craft`：作品（提示词、推荐、选择、实例快照、简谱、会话记录）；
- `jianpu`：简谱（标题、调、调式、BPM、风格、Bias、每小节 8 格、技巧、走向快照、实例 id）；
- `tablature`：六线谱（`tab-<简谱 id>`，文本内容）。

保存简谱会同时写这两条；删除简谱会连同它的六线谱一起删。上次保存/载入的谱面会记在
`improv.lastScore`，重启后自动恢复，不用再翻库。

#### API 配置与安全

- API 配置放在 **设置 dialog** 里（右上角齿轮），不在页面里展开一堆输入框；
- 厂商下拉预设 **DeepSeek**（`https://api.deepseek.com`，`deepseek-chat`）和 **OpenAI**（`https://api.openai.com/v1`，`gpt-4o-mini`），
  也可以选「自定义（OpenAI 兼容）」填自己的 Base URL / 模型；
- **测试连接**会发一条只要求 JSON 的极小请求，显示耗时、模型名与 token 数；
- Key 只保存在本机 SQLite（桌面浏览器是 localStorage），**不会打进 APK，也不会写进本仓库**；
- 地址请用 **https**（Android 默认拦截明文 HTTP）；
- 用别人的设备时注意：Key 是明文保存在应用私有目录，清除应用数据会一起删掉。

## 六、直达链接参数

在浏览器或 WebView 里可以用 hash 直接指定状态，方便收藏某一次查询：

| 参数 | 取值 | 例子 |
| --- | --- | --- |
| `key` | 0–11（C=0, C♯=1, …） | `key=7` → G 调 |
| `scale` | `major` / `minor` / `harmonic` | `scale=minor` |
| `degree` | 1–7 | `degree=5` |
| `acc` | -1 / 0 / 1 | `acc=-1` → ♭级 |
| `q` | 属性 id，如 `maj` `m` `7` `maj7` `m7` `sus4` `dim` `9` … | `q=maj9` |
| `maxFret` | 12 / 15 / 17 / 19 / 21 / 22 / 24 | `maxFret=17` |
| `span` / `minSounding` | 3–5 / 2–6 | `span=5` |
| `bass` | `any` 表示低音不限（看转位） | `bass=any` |
| `flat` | 1 / 0，用降号还是升号拼写 | `flat=1` |
| `sheet` | 1 表示加载后直接展开条件面板 | `sheet=1` |
| `tab` | `chord`（默认）/ `tuner` 调音 / `band` 伴奏 / `improv` 即兴 | `tab=improv` |
| `sub` | 伴奏页的子页签：`drums` / `backing` | `sub=backing` |
| `mode` | 调式 id：`major` `minor` `harmonic` `ionian` `dorian` `phrygian` `lydian` `mixolydian` `aeolian` `locrian` | `mode=dorian` |
| `a4` | 调音基准音（400–480） | `a4=432` |
| `debug` | 1 时把关键元素坐标与点击落点写进 logcat（真机排查用） | `debug=1` |
| `pattern` | 鼓机节奏 id（如 `rock` `blues` `funk` `waltz`） | `pattern=blues` |
| `bpm` | 伴奏速度（40–240） | `bpm=96` |
| `prog` | 和弦走向 id（如 `pop4` `canon` `blues12` `jazz251`） | `prog=blues12` |
| `rhythm` | 节奏型 id（如 `arp5321` `strum_folk` `strum_mute`） | `rhythm=strum_folk` |

例：`index.html#key=9&scale=minor&degree=4&q=m7&maxFret=17` = A 自然小调 iv 级小七和弦、指板到 17 品。
例：`index.html#tab=tuner&key=0&mode=dorian` = 直接打开「C 多利亚」的调音与音阶指板。
例：`index.html#tab=band&pattern=blues&bpm=96&prog=blues12&rhythm=arp5321`
= 打开伴奏，鼓机用蓝调摇摆、和弦走十二小节布鲁斯、节奏型用 53231323，速度 96。
例：`index.html#tab=improv` = 直接打开独立的「即兴」页（先在伴奏页保存一个实例）。

安卓上也可以用 intent 直达（方便自己测试）：

```bash
adb shell "am start -n com.chord.helper/.MainActivity --es hash \"tab=tuner&mode=dorian&debug=1\""
```

### 调音怎么测（不需要真麦克风）

调音的音频链路可以在电脑上验证：往页面里注入一个已知频率的振荡器，跑完整条
「音频 → 基频 → 音名/级数/弦识别 → 指板高亮 → 界面读数」链路并断言：

```bash
python tools/run_audio_test.py            # 注入振荡器（最稳，推荐）
python tools/run_audio_test.py --mic      # 走真实 getUserMedia + 假麦克风播放 test-tone.wav
```

真机上想看麦克风权限流程和实际收音，用：


### 鼓机与和弦伴奏怎么测

两者都是「自己发声」的，所以测试办法是：用 `OfflineAudioContext` 把内容**渲染成一段真实音频**，
再从波形里核对每一处该响的地方：

```bash
python tools/run_audio_test.py --page drums      # 鼓机 + 实时伴奏引擎 + 六种吉他音色，共 42 条断言
```

覆盖的内容包括：底鼓/军鼓落在正确的拍子上、摇摆确实把反拍推后了 1/3 格、切音（X）明显比正常扫弦短、
伴奏的每个拍点都有起音而半拍处没有多余声音、以及**和弦的根音落在正确的弦和品位上**
（C → 5 弦 3 品 MIDI 48、G → 6 弦 3 品 MIDI 43）。

（调音与鼓机共用这个脚本：`python tools/run_audio_test.py` 测调音，`--mic` 用假麦克风测真实收音。）

### 一条命令跑完所有自检


## 十、常见问题

**Q：为什么某个和弦查不到指法？**
默认条件比较严格：至少 4 根弦发声、跨度不超过 4 品、低音必须是根音、发声弦必须连续。放宽其中任意一条都能查到更多，页面在查不到时也会提示。想看转位指法，关掉「低音必须是根音」。

**Q：指法是不是"标准指法"？**
不是。它是**按规则穷举出来的所有可行按法**，再按把位和发声弦数排序，所以既有你熟悉的 `x32010`，也会有一些不常见的变体。指法圆点里的数字是按品的先后顺序推断的（横按优先给食指），仅供参考。

**Q：为什么和弦图里有的和弦不带五音？**
因为查询不要求五音必须出现（`C` 只需要根音和三音）。这是吉他上的常规做法——去掉五音反而更容易按，听感上也不缺。

**Q：能改成其他调弦吗？**
可以，`js/chord.js` 顶部的 `TUNING` 数组就是 6 根弦的 MIDI 音高，改掉即可（例如 Drop D 把第一项改成 38）。

**Q：调音没反应 / 一直显示 -- ？**
先确认点过“开始收音”并且给了麦克风权限；如果提示“被其它应用占用”，关掉录音或会议类应用再试。
读数出现 `--` 表示当前环境太安静（低于阈值就不猜），对着麦克风正常拨弦即可。
桌面浏览器里 `file://` 页面可能被拦截录音，用手机装 APK 最稳。

**Q：调音准不准？**
基频检测在合成波形上验证到 ±0.5Hz（六根弦空弦音 + 高把位都测过），音分精度 ±1；
真机还会受手机麦克风与琴体共振影响，调标准音时看“音分”最直观。

**Q：为什么调式里的级数要按“同主音大调”算？**
这是教会调式最通用的说法（也是你给的那张表的写法）：多利亚的特征音就是 ♭3、♭7。
所以 C 多利亚的音阶指板上，第 7 个音显示 `♭7 / B♭`，而不是 `7 / B♭`。

**Q：鼓机没有声音？**
先确认点的是「开始」而不是切换了节奏；如果整机静音或媒体音量为 0 也会听不到（应用不会绕过系统静音）。
网页版在部分浏览器里需要先点一下页面（用户手势）才允许出声。

**Q：鼓点听着不像真的？**
音色是纯合成（正弦/噪声 + 包络），目标是“节拍稳、好跟”，不是仿真实鼓组。
想要更好的音色可以把 `drums.js` 里的合成参数（`LEVEL`、包络时间）调一调，或者换成采样音频；
和弦音色在 `audio.js` 的 `pluck()` 里。

**Q：和弦伴奏弹出来的和弦听着不对/和指法不一样？**
伴奏用的是「最低把位、开弦最多」的那个指法（和吉他手第一反应一致），所以和你手上按的和弦图可能不是同一张。
想换就用「和弦查询」页看其它把位——伴奏的音高是按它自己挑的指法走的。

**Q：动了个别和弦的拍数，为什么听不出变化？**
走向的改动在**下一小节**生效（引擎正在读的就是那份数据，不用重启）。如果鼓机和伴奏都启用，
请确认总控里的速度是你要的——所有引擎共用一个 BPM，改一处全部一起变。

**Q：为什么伴奏切页签还在响？**
这是故意的：练和弦转换时你要一边看指法一边跟节奏。不想听就点底部的迷你播放条上的「停止」。

**Q：即兴页生成了但没声音 / 只听到伴奏？**
- 先在伴奏页保存一个**伴奏实例**并在即兴页选中它，或者直接写提示词（提示词不为空时可以没有实例，推荐流程会自动建一个）。
- 看模式条：橙色 `本地 solo` 是规则生成，绿色 `LLM solo · 模型名` 才是大模型；点右上角 **设置**（齿轮）填 Key 并测试。
- 生成确认后会播放；之后也可以在作品详情页点 **播放作品**。
- 三路音量里把 **solo** 调大（默认 120%），伴奏被自动让到 75%，不会被盖住。
- 迷你条出现 `SOLO E4`、上方“正在演奏…”和左指板实心点，说明 solo 在响；如果这些在动但听不见，
  检查手机媒体音量、是否装了最新 1.3.0 APK。
- 想只听 solo：把鼓/伴奏滑杆拉到 0；想听完整伴奏就恢复。

**Q：solo 指板为什么总在 6 品 / 只用高音弦？**
这是旧版每 2 小节重新选把位造成的。1.2.4 起整段只用一个指型：
默认「自动」会按整段音域选覆盖最多的一个；也可以在旋律指板下面的 **指型** 下拉里
指定 自动 / Mi / La / Si / Re / Sol。选项里会写当前调的品格范围（C 调 Mi 0–6、La 5–8）。
如果有音超出范围，主指型保持不变，**超出部分自动换把位并画出来**（窗口中扩展 + 虚线圈），
同时提示可换哪个指型；不会自动把整段指型切走。

**Q：上一小节以延音结尾，下一小节为什么没有滑音了？**
这是刻意改的。滑音/推弦/击勾弦现在要求前一个位置是**实际拨响的音符**；
上一小节最后一格是延音 `-` 或休止 `0` 时，校验器会拒绝这类技巧，
避免出现“手指还按在延音上，下一小节却要求滑过去”的假动作。

**Q：伴奏实例很多时怎么找？**
即兴页的实例区有搜索框，可以输实例名、和弦走向、调式、节奏型或 BPM；
下拉框只显示匹配项，清空搜索就恢复全部。

**Q：保存后以后怎么再听、再改？**
- 带提示词生成的作品会自动进 **作品** 页签：点 **打开** 进详情页，**播放作品** 会带鼓机/伴奏/solo一起播；
  下面的 **继续修改** 可以直接让 AI 改谱，消息和结果都存回这条作品。
- 老的单条简谱在 **作品 → 简谱库**：每条行尾有 **播放**，
  它会先载入这条谱，再按保存时关联的实例带鼓机/伴奏/solo 播放；关联实例被删了，
  或这条谱是文本/图片导入的，就只播旋律。行内的「走向：… · 实例：…」就是来源；
  点 **载入** 只放到编辑区，不自动发声。

**Q：为什么走向库里一下多了 54 条？**
新增了从常见华语流行走向整理的「歌曲 / 情绪」走向和一批扩展进行，现在共 63 条。
它们仍按当前主调整体移调，说明里保留原调和弦名；可以用情绪（如“清新”）、
标签（“歌曲”）、和弦名（如 `Am F C`）或编号（`4536251`）搜索。

**Q：伴奏实例是什么？会跟着伴奏页变吗？**
实例是保存那一刻的快照：鼓机格子（含你的改动）+ 和弦走向 + 节奏型 + 调式/速度。
之后在伴奏页换走向/改格子不会影响已保存实例；要更新就再保存一个。即兴页按实例写 solo。

**Q：任务队列会保留到下次打开吗？**
不会。队列是内存 FIFO，同时只跑一个；关闭应用后排队/运行中的任务会清掉，
但已经保存到简谱库的结果还在，可以重新“载入”。这避免后台重启后自动发请求、重复花钱。

**Q：思考过程为什么不是逐字蹦出来？**
安卓上走原生 SSE，确实是边收边显示；但界面会把 JSON 里的
`thinking / structure / motif / review / reason` **整理成段落**，所以看起来像“分段出现”，
而不是把原始 JSON 字符一个个刷出来。少数服务不支持 `stream + response_format` 时会自动回退整段返回。

**Q：即兴必须联网 / 必须买 API 吗？**
不必须。和弦、调音、鼓机、伴奏、实例、作品、谱库都离线；不填 API 时点「生成」会走本地规则作曲（包括提示词→本地推荐→选 BPM 的完整流程）。
只有配置了 API 后，生成、推荐和作品会话修改才会请求你自己的模型服务，费用由你的 API 账号承担。

**Q：风格、音色、长度和音量在哪？**
即兴页的下拉框：风格 7 种（五声/布鲁斯/蓝调/大调/自然小调/多利亚/混合利底亚）、
长度 1/2/3 loop（默认 1）、音色 6 种（含电吉他过载、失真）。再下面是鼓/伴奏/solo 三路音量滑杆。
超过 1 loop 时实例走向会自动循环（4 小节实例选 2 就是 8 小节）。

**Q：我的 API Key 存在哪？安全吗？**
只存在本机：安卓是应用私有目录里的 SQLite `settings` 表，浏览器预览是 localStorage。
APK 和本仓库里**没有**任何 Key；Key 不会发到除你配置的服务端之外的任何地方。
注意它是明文保存的，清除应用数据会一起删掉；不要把装了 Key 的手机借给别人。

**Q：设置在哪里？怎么换浅色/深色？**
右上角齿轮打开「设置」，里面就是厂商 / Base URL / 模型 / API Key、测试连接和「外观主题」。
主题有跟随系统 / 浅色 / 深色三选一，立即生效并保存；和弦查询里的另一个齿轮是查询条件，不是设置。

**Q：推荐面板里点了速度，为什么没有开始生成？**
这是故意的。点速度只把 BPM 记到草稿里，你还可以继续改鼓机、节奏型和和弦走向；
确认后点 **用这些选择生成**（或主按钮「生成」）才会真正建立实例并调用模型。

**Q：简谱数字上方/下方的小圆点是什么？**
上方是高八度、下方是低八度，一个点差一个八度；没有点就是该调的中音区。
数字下方的音名（如 `A3`）也带八度，可以对照。`—` 表示延音/连音，不是休止。

**Q：为什么生成的旋律有时连着好几个 `—`？**
这是为了让长音跨过拍点，情绪更连贯。生成后会主动补延音，但每小节仍保留至少 4–5 个起音；
如果觉得太拖，可以在会话里说“少一点延音、多一点连续八分音符”，让 AI 重写一个版本。

**Q：作品详情页怎么回去？**
详情页最上方有一个固定的 **← 返回作品库** 按钮，滚动到任何位置都能点；它会回到顶部「作品」页签，而不是即兴页。

**Q：调音在哪里？**
不再占顶部页签。点右上角、设置左边的调音按钮，会以全屏 dialog 打开；右上角「关闭」退出并释放麦克风。

**Q：作品库为什么不在即兴页了？**
顶部新增了 **作品** 页签，就在「即兴」右边；作品库、简谱库、六线谱库都在这里。即兴页只保留生成和工具。

**Q：推荐速度为什么有两个？**
推荐 agent 会先给一个最合适的 `bpm`（显示在「推荐速度」按钮里），再给 5 个备选 Top5 供快速选择；你也可以直接在数字框输入任意 40–240 BPM。点它们都只记录选择，最后仍要点生成。

**Q：作品详情页的会话修改为什么失败？**
会话修改需要调用模型，先在设置里填好 API。没有配置时仍可打开作品、播放和查看已有会话；
发送修改会提示“还没有配置 API”，并把这条失败回复记进会话，配好之后可以继续改。

**Q：DeepSeek 为什么不能识别简谱图片？**
`deepseek-chat` 是纯文本模型，不接受图片输入。图片识别请选 OpenAI（如 `gpt-4o-mini`）或
「自定义」里填一个多模态模型的地址；否则用「文本导入简谱」，功能一样能走通。

**Q：生成失败 / 提示模型没返回 JSON 怎么办？**
先点「测试连接」确认地址、模型名、Key 都对；再检查网络与余额（401/403/429 会给出中文提示）。
流水线对解析失败会自动重试一次；主控或衔接失败会降级继续，填音失败才整条失败。
实在不行清空提示词、选一个伴奏实例后点「生成」，用本地规则先出一版；或者把 Bias 调低（0–20 只用和弦音，模型更容易写对）。

**Q：即兴旋律听起来有点重复 / 太密？**
风格与 Bias 会直接影响密度：Bias 低时只允许和弦音、留白更多；Bias 高时允许半音经过音，会更“花”。
本地 solo 是规则作曲，重复感比大模型明显；接上 API 后同样的走向会每次不同。
也可以先在「伴奏」里换一条更有起伏的走向，再生成。

**Q：Android 5.0 上即兴连不上 API？**
本地功能不受影响。Android 5 的系统 TLS 栈比较旧，部分模型服务（要求 TLS 1.2/1.3）可能握手失败；
联网的即兴功能建议在 Android 7+ 上使用。

**Q：需要嵌入 Python 或 LangGraph 吗？**
不需要。四个 agent 就是四段带 JSON 契约的提示词，编排是手写的 Promise 链；
页面跑在 WebView 里，联网通过安卓壳的原生 HTTP 桥（`HttpBridge.java`）发出去。
这样 APK 不用带 Python 运行时，也不用引入任何第三方依赖。

**Q：简谱、六线谱、作品是几个数据库？**
底层是一个 SQLite 文件 `chord.db`，`items` 表用 `kind` 分成 `instance` / `craft` / `jianpu` / `tablature` 命名空间；
界面上「我的作品」有作品库 / 简谱库 / 六线谱库三个页签（各自的搜索、分页、删除）。
craft 是完整创作快照（提示词/推荐/选择/实例/旋律/会话），保存简谱会自动附带六线谱；
伴奏实例则是即兴页取素材用的另一个命名空间。

**Q：在很老的手机上界面为什么是简化样式？**
Android 5.x 出厂自带的 WebView 是 2014 年的 Chrome 37，不支持 CSS 变量，所以颜色/间距会降级成简化版
（功能完全正常，界面会多一条提示条）。到应用商店更新「Android System WebView」就恢复完整样式——
真机上 WebView 是独立更新的，绝大多数设备早已是新版本。本项目已在 Android 5.0 模拟器上实测过这条降级路径。

**Q：怎么确认我的手机能不能跑？**
装上去打开即可。如果是白屏或崩溃，用数据线连电脑跑 `adb logcat -s ChordHelper:I`，
App 会把页面标题、卡片数量、页面底色、脚本错误都打进日志（`dom={...}` 那一行），一眼能看出问题在哪。

**Q：为什么界面是网页做的？**
因为指板/和弦图本质是 2D 矢量绘制，用 SVG 表达最直接，改一行刷新就能看到效果，也方便在电脑浏览器里调试。详细取舍见 `process.md`。

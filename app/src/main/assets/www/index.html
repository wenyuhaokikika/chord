和弦助手 · 和弦 / 调音 / 伴奏 / 作品库完全离线；只有「即兴」生成和「作品」会话修改配置并使用 AI 接口时才会联网。标准调弦 EADGBE。（调音需要麦克风权限）

  

    使用说明
    
    
      
  1. 和弦查询：点顶部 ⚙ 打开条件面板，先选主调、再选级数（可加升降号），最后选和弦属性。
    2. 
      
  2. “调内和弦”一排是当前调的自然和弦，点一下直接查询。
    3. 
      
  3. CAGED：和弦页先看 C/A/G/E/D 五张代表指型卡，先记形状和根音位置；点卡片会在指板上高亮。需要更多按法时再展开「全部指法（高级）」。
    4. 
      
  4. 指板默认 24 品，可在条件面板里调整；点任意指法卡片可以在指板上高亮该指法。
    5. 
      
  5. ◀ / ▶ 在全部指法之间切换，♪ 试听当前指法（扫弦）。
    6. 
      
  6. 调音 · 音阶：点右上角、设置左边的调音按钮，以 dialog 打开；先选主调与调式（点 ⚙），再点“开始收音”；右上角「关闭」退出并释放麦克风。
    7. 
      
  7. 伴奏：上面选速度（也可以 TAP 点速），下面两个子页签——鼓机（节奏 + 自己点格子）和伴奏（调式、63 条和弦走向、节奏型；可搜情绪/标签/和弦）。两个都启用就会一起响，拍点自动对齐。
    8. 
      
  8. 伴奏实例：在伴奏页把「鼓机（含格子改动）+ 和弦走向 + 节奏型 + 调式/速度」保存成实例；即兴页可以输入名字/走向/调式搜索，再选择作为素材。
    9. 
      
  9. 即兴（顶部独立页签）：可以填一个场景提示词（例如“凄凉的秋天，一个老人扫落叶”）。填了会先让推荐 agent 给出鼓、节奏型、和弦走向、1 个推荐速度和 Top5 备选；速度可以点选或直接输入，改完点 用这些选择生成 才生成；不填就按当前伴奏实例生成。页面主操作只有 生成 和 保存。风格 7 种、音色 6 种、长度 1–3 loop、离调 Bias、音域 Bias、三路音量；播放时双指板显示音名和当前音。
    10. 
      
  10. 设置：点右上角齿轮，填写厂商 / 模型 / API Key，并选择浅色、深色或跟随系统主题。Key 只保存在本机。
    11. 
      
  11. 作品：即兴右边的顶部页签。一个作品（craft）包含提示词、推荐、你选的速度、伴奏实例（鼓/节奏型/走向）、简谱和后续修改会话；点作品进入独立详情页，左上角 ← 返回作品库。旧简谱库和六线谱库也在「作品」里。
    12. 
      
  12. 作品详情：显示提示词、推荐与选择、和弦图/节奏预览、双吉他指板、三声部音量、分页版本表格和简谱；底部可以继续对话，例如“第二小节轻一点”，修改结果、版本和会话都会写回 SQLite。
    13. 
      
  13. 谱记法：x = 闷弦，0 = 空弦，数字 = 品位；圆点里的数字是建议指法（1=食指 … 4=小指）。
    14. 
      
  14. AI 接口：点右上角「设置」，在弹窗里选厂商、填模型与自己的 Key，点「测试连接」。Key 只保存在本机；DeepSeek 聊天模型不支持图片识别，图片请用多模态模型或文本导入。
    15.
